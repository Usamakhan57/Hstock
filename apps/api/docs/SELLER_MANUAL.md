# Seller Manual — ApnaStore v1.0

## Account

1. Register as a seller (`/seller/register`)
2. Registration fee defaults to **0** (configurable by admin)
3. Sign in at `/seller/login`
4. Complete store profile settings

## Products

From **Seller Dashboard → Products**:

- Create product (accounts, licenses, digital files, etc.)
- Edit draft / live listings
- Submit for moderation when required
- Delete / archive products you no longer sell

Global asset uniqueness applies — duplicate identifiers are rejected.

## Orders & fulfillment

- New paid orders appear under **Orders**
- Deliver digital goods / credentials per product type
- Escrow holds seller funds until auto-release or dispute outcome

## Wallet, ledger & withdrawals

1. Released escrow credits your seller wallet
2. Review ledger entries under earnings/wallet views
3. Request a withdrawal to an approved crypto address
4. Admin reviews → Approves → Marks **Paid** after external payout

## Disputes & replacements

- Respond in secure dispute chat
- Upload evidence when requested
- Send replacement accounts for disputed quantities
- Undisputed items continue normal escrow release

## Notifications

Seller dashboard notifications cover new orders, escrow releases, withdrawals, and disputes.
